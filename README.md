# Hola, soy Cristian Amigo 👋

Vengo del soporte y la infraestructura de TI, y hoy estoy formándome como
**desarrollador Java backend**. Me interesa la parte del software que no se ve: cómo se
guardan los datos, cómo se protege el acceso y cómo dos sistemas se ponen de acuerdo para
hablar entre ellos.

## En qué ando

Estoy cursando un bootcamp de desarrollo full stack Java, y en paralelo aplico lo que
aprendo a proyectos propios. Prefiero terminar cosas chicas que funcionen de verdad antes
que empezar cosas grandes que queden a medias.

## Tecnologías

**Con las que trabajo hoy**

- Java 21 · Spring Boot · Spring MVC · Spring Data JPA · Spring Security
- SQL (PostgreSQL, MySQL, SQLite) y modelado relacional
- JUnit 5 y Mockito para pruebas
- Git y GitHub · Maven
- HTML, CSS, Bootstrap y JavaScript para la capa de vista

**Que sigo aprendiendo**

- Diseño de APIs REST y autenticación con JWT
- Docker y despliegue en la nube
- Arquitectura por capas y buenas prácticas de diseño

## Qué me gustaría desarrollar

Aplicaciones de gestión con API REST detrás: sistemas donde varias personas con distintos
permisos trabajan sobre los mismos datos y todo queda registrado. Me interesa especialmente
la parte de integración — que un sistema le entregue datos a otro sin intervención manual.

## Un dato personal

Pasé cerca de diez años arreglando lo que otros construían, en soporte técnico. Eso me dejó
una costumbre difícil de sacar: antes de dar algo por terminado, lo levanto y lo pruebo.
Que un programa compile sin errores no significa que haga lo que promete, y esa diferencia
me la enseñó el turno de noche, no un manual.
